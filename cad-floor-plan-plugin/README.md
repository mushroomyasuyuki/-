# 壁紙・カーペットシミュレーション（CAD対応）

マッシュオフィス様の「壁紙・カーペットシミュレーション」を WordPress プラグインにまとめたものです。

- 壁紙・カーペットのデザイン減色、見積もり、お部屋パース（簡易パースプレビュー）、壁紙の入稿データ作成（元のツール）
  - 減色後の床・壁紙のデザインは、お部屋パースとCAD表示の3Dの両方に、自動で反映されます（CAD表示では、床は①カーペット用の減色イメージ、壁は②壁紙用のデザイン画像を、それぞれ適用します）
- DXF / ベクターPDF / JSON / PNG・JPEG の間取りを3D表示し、床・壁の面積を計算する **CAD表示**
- 注文メール送信（デザインファイルを60日間保存し、ダウンロードリンクをメールで送る **Design Order Mailer** を同梱）

現在のバージョン: **2.67.1**（変更履歴は [CHANGELOG.md](CHANGELOG.md)）。ファイルの解析はすべてブラウザ内で行われ、間取りデータはサーバーに送信されません。

## インストール

1. zip を、管理画面の「プラグイン」→「新規追加」→「プラグインのアップロード」でインストールし、有効化します。
2. **有効化すると、固定ページ「壁紙・カーペットシミュレーション」（URLも同名）が自動で公開されます。** 中身は元のツールにCAD表示を組み込んだものです。Cocoon の場合は、ページ設定が「本文のみ（フルワイド）」「タイトルを表示しない」「読む時間を表示しない」「目次を表示しない」になります（他のテーマでは無視されます）。
   - **無効化すると、このプラグインが作ったページは完全に削除されます。** 再度有効化すると作り直されます。
   - すでに同じURLのページがある場合は、そのページを消さず、別URL（末尾 `-2`）で作成します。既存ページを削除またはURL変更してから、新しいページのURLを直してください（管理メニュー「壁紙・カーペット」に案内が出ます）。
   - ショートコード `[wallpaper_carpet_simulator]` を入れた既存ページがあれば、それを使います（無効化しても削除しません）。
3. 注文メールの受信先は、「設定」→「Design Order Mailer」で変更します（未設定ならサイト管理者のメールアドレス）。

### 元の Design Order Mailer プラグインを使っているサイトの場合
元のプラグインが有効な間は、そちらを使い、同梱版は停止します（二重送信を防ぐため）。保存済みファイルと設定はそのまま引き継げます（同じテーブル・設定を使います）。元のプラグインを無効化すると、同梱版に切り替わります。

## 作業の途中保存と再開

お客様が作業を途中でやめて、後日続きから再開できます。

- **途中保存してリンクを受け取る**（ツール上部の紫の欄）：メールアドレスを入れて押すと、画像（床・壁紙の元画像）・読み込んだ図面・入力内容をサーバーに保存し、再開用リンク（ページURL + `?cfp_resume=…`）をメールで送ります。リンクを開くと、パソコン・スマートフォンのどちらからでも続きから再開できます。再開後にもう一度保存すると、同じリンクのまま内容と期限が更新されます。
  - 保存期間は30日（`cad-floor-plan.php` の `CFP_RESUME_DAYS`）。期限を過ぎたものは毎日のcronで自動削除します。
  - 保存先は `wp-content/uploads/cfp-resume-private/`（直接アクセス禁止）。合計150MBまで（フィルター `cfp_resume_max_total_bytes`）。
  - 「著作権に抵触しない」のチェックは保存しません（再開後に改めて確認していただきます）。
- **この端末への自動保存**：作業内容を自動でブラウザ（IndexedDB）に保存し、同じ端末・同じブラウザで次に開いたとき「続きから再開する／破棄して最初から」を表示します（30日で削除。サーバーには送りません）。

## 注意
- 「制電マーク」「防炎マーク」は、メディアライブラリの画像から自動で探して表示します（画像のタイトルに「制電マーク」「防炎マーク」を含むもの。例: `seiden_mark_制電マーク.jpg`、`bouen_mark_防炎マーク.jpg`）。`assets/badges/` に `seiden.png`（制電）・`bouen.png`（防炎）を置いた場合は、そちらを優先します。画像が見つからない間は、マークは表示されません。
- 注文メールを送る前に、「品質基準について」（`templates/wallpaper-carpet-tool.html` の `cc-quality-doc` に全文）を最後までスクロールして読み、同意のチェックを入れる必要があります（著作権のチェックの右）。文面を直すときは、このHTMLを編集してください。
- 製品仕様のカットパイル・ループパイルのカードの写真は、ファイル名 `carpet-cut-pile.jpg`・`carpet-loop-pile.jpg`（jpeg / png / webp も可）で探します。`assets/img/` に置くか、メディアライブラリにアップロードしてください（見つからない間は写真を表示しません）。
- 壁紙・カーペットツールの見た目や文言を変えるときは、`templates/wallpaper-carpet-tool.html` を編集します（`[cad_floor_plan]` の行はCAD表示の差し込み位置です）。

## 図面の読み込み（サイズの反映・部屋の選択）

CAD の欄にDXF / PDF / JSON / PNG・JPEGの図面を入れると、次のように動きます。

1. **部屋の検出**: 閉じた図形（0.5㎡以上）を部屋として読み取ります。図面内の文字（部屋名）が部屋の中にあれば、その名前を使います（数字だけの文字は除きます）。
2. **部屋が複数あるとき**: 平面図に番号付きで全部屋が表示されます。平面図の部屋をクリックするか、一覧から選ぶと、その部屋が3Dで表示されます（最初は最大の部屋）。
3. **サイズの反映**: 選んだ部屋の幅×奥行を、見積もり・お部屋パース・壁紙のサイズに自動で設定します。
   - カーペットの横幅・縦幅: 50cm角を部屋の中心から割り付けた枚数 × 500mm（端で切れるタイルも1枚。下の「カーペット割付」）。
   - お部屋パース・壁紙のサイズ: 幅・奥行き・壁の高さ（壁の幅と高さは、壁紙PSDと注文にも使います。壁の高さは図面にないため、既定の2,400mm。JSONでは `walls[].height` で指定可）。
   - 四角でない部屋（L字など）は、見積もりが外接する四角で計算されます。実際の床面積は画面に表示されます。
   - 「図面のサイズを見積もり・お部屋パース・壁紙サイズに反映する」のチェックを外すと、反映しません（手入力のサイズを守れます）。サンプルの表示では反映しません。
4. **単位**: DXFは図面の設定（`$INSUNITS`）を使います。設定がない図面は、図面の大きさから mm / cm / m を自動判定します。違っていれば、画面の「DXFの単位」で指定してください。PDFは「PDFの縮尺」で指定します。
5. **文字コード**: DXFが古い形式（Shift_JIS など）でも、部屋名を読み取れます。

## カーペット割付（50cm × 50cm）

図面を読み込んで部屋を選ぶと、「カーペット割付」の欄に、50cm角のタイルカーペットを部屋の中心から割り付けた線を赤線で表示します。

- 端で切れるタイル（薄い赤）も1枚として数え、見積もりのカーペットサイズ（横幅・縦幅）＝割付の枚数 × 500mm に反映します。部屋に実際に敷く枚数（うち端で切る枚数）も表示します。
- **割付を移動**：ドラッグで割付全体をずらせます（250mm＝タイル半分ずつ動きます。矢印キーで250mm、Shift+矢印で500mm）。最初は、部屋の中心（赤い「センター」印）にタイル1枚の中心が合います。ずらすと見積もりも更新します。「中心に戻す」で元に戻ります。
- **変換画像を重ねる**：①カーペット用の減色イメージを、割付の上に重ねて表示します（最初は割付の範囲＝見積もりサイズに合わせます）。「画像を移動」のドラッグ（矢印キーで10mm、Shift+矢印で100mm）で位置、「画像の大きさ」（20〜300%）で大きさ、「画像の濃さ」で透け具合を調整できます。
- **中心に戻す**：割付と画像の位置・大きさを元に戻します。
- **画像をカーペット割付の範囲まで表示**：オンのとき、変換画像を割付の範囲（見積もりサイズ）の中だけに表示します。PSDは、このチェックに関係なく、常に割付の範囲まで表示して保存します。
- **割付をPSDで保存**：画面で調整した状態を、レイヤーに分けたPSDで保存します（①元図面／②部屋／③画像（不透明）／④割付）。実寸で 1px = 1mm（長辺が8,000pxを超える場合は縮小）。
- **図面を表示／割付を表示／変換画像を表示**：チェックで表示を切り替えます。

## 画像（PNG / JPEG）の図面

スキャンした図面や、間取り図の画像も入稿できます。中身が画像のPDFも、同じ方法で読み取ります。

1. 画像を入れると、線で囲まれた部分を部屋として読み取り、元の画像に重ねた平面図に表示します。検出の結果を目で確かめてください。
2. **縮尺の設定（必須）**: 画像には縮尺が無いため、選んだ部屋の「横幅」または「奥行」の実際の長さ（mm）を入力し、「この大きさにする」を押します。図面に書かれた寸法（例: 「LDK 3,600」）を使ってください。全部屋の大きさが、この縮尺で決まります。入力するまでは「（仮）」と表示し、見積もり・壁紙サイズには反映しません。
3. **うまく読み取れないとき**:
   - 部屋がつながって1つになる → 「すき間を閉じる」を大きくします（ドアの開口や線の途切れを閉じます）。
   - 線が薄い・細くて検出されない → 「線を検出する濃さ」を上げます（「自動」が既定です）。
4. 部屋の中の家具などの囲みは、部屋として数えません。ほぼ長方形の部屋は、きれいな長方形に整えます。L字などの形は保ちます。
5. 部屋の名前は読み取れません（「部屋 1」「部屋 2」…）。図面内の文字（OCR）には対応していません。
6. 大きな画像は、長辺 1,200px に縮小して処理します。

## 図面の上で部屋を指定（手動）

壁・寸法線・通り芯・家具が重なった CAD の平面図（PDF）などは、部屋が閉じた線になっておらず、自動では部屋を読み取れません。その場合は、図面の上で部屋を自分で囲んで指定できます。

- **開き方**: PDF・画像を読み込むと出る「図面の上で部屋を指定」ボタン。自動検出が20個を超える図面では、自動で開きます（自動検出は隠します）。
- **四角**: 部屋の対角の2点をドラッグします。
- **多角形**: 部屋の角を順にクリックし、最初の赤い点をクリック（またはダブルクリック、Enter）で確定します。「角を直角にそろえる」で、前の点と水平・垂直にそろいます。Esc で取り消し、Backspace キーで1点ずつ戻せます。
- **拡大・縮小・移動**: ホイールで拡大・縮小、「移動」（または中ボタンのドラッグ）で動かせます。「全体」で全体表示に戻ります。
- **部屋を移動**: 「部屋を移動」を選び、手で指定した部屋（緑の枠）をドラッグすると、図面はそのままに枠だけを動かせます（大きさ・形は変わりません。Escで取り消し）。展開図の「範囲を移動」も同じです。
- **形を変える**: 「形を変える」を選ぶと、手で指定した部屋の角に白い丸、辺の中央に小さな四角が出ます。白い丸をドラッグで角を移動、四角をドラッグで角を追加、白い丸をダブルクリックで角を削除します（3つ以上は残ります。Escで取り消し）。「角を直角にそろえる」がオンなら、隣の角と水平・垂直にそろいます。展開図の「範囲の形を変える」も同じです。
- **部屋の追加と削除**: 指定した部屋は一覧に追加され、「×」で削除できます。「自動で出た部屋を隠す」で、自動検出した部屋の表示を切り替えられます。
- **大きさ**: PDFは「PDFの縮尺（1:N の N）」で決まります（図面の表題欄の縮尺を入力してください。例: 100）。画像は「この大きさにする」で、選んだ部屋の横幅または奥行の実際の長さを入力します。縮尺が決まるまでは「（仮）」と表示し、見積もりには反映しません。

## 対応形式

| 形式 | 読み取る内容 |
|---|---|
| DXF | 閉じた `LWPOLYLINE` / `POLYLINE`、およびつながって閉じる `LINE`。単位は `$INSUNITS` から換算（なければmm） |
| PDF | 1ページ目のベクター図形（CADや Illustrator から書き出したもの）。縮尺は画面の「PDFの縮尺（1:N）」に N を入力。スキャンしたPDF（画像）は、自動で画像として読み取ります（下の「画像の図面」を参照） |
| JSON | 下記の形式 |
| PNG / JPEG（WebP） | 画像の図面。線（暗い部分）で囲まれた明るい部分を部屋として読み取ります。下の「画像の図面」を参照 |
| DWG | 直接は読めません。DXFに書き出してください |

- 0.5㎡未満の閉じた図形は、家具や記号などのノイズとして無視します。
- 線が枝分かれしている図面（壁の交差点がある図面など）は、閉じた輪郭として認識できません。外形を閉じたポリラインで描いてください。
- 曲線（円弧・スプライン）は直線近似または未対応です。
- DXFのブロック（INSERT）の中の図形や文字は、読み取れません。部屋の外形は、ブロックにせず描いてください。

```json
{
  "rooms": [
    {
      "id": "room_1",
      "vertices": [[0, 0], [6000, 0], [6000, 2500], [3500, 2500], [3500, 5000], [0, 5000]],
      "walls": [{ "height": 2400 }]
    }
  ]
}
```

座標はmm、Y軸は上向きです。`walls` は省略でき、省略すると各辺を高さ2400mmの壁にします。

## 図面を複数読み込む（平面図と展開図）

CAD の欄には、図面を複数まとめて入れられます（ファイル選択で複数選ぶ、または複数ドロップ）。

- 読み込んだ図面は「平面図（床 → カーペット）」「展開図（壁 → 壁紙）」に分けて表示します。
- **床か壁かの判別**: PDFは、壁の高さの表記（▼FL と天井高）と寸法から壁を読み取れたら展開図です。読み取れなくても、「展開図」「立面図」「姿図」「ELEVATION」の表記が「平面図」「間取」などより多ければ展開図とします。それ以外は平面図です（▼FL などの高さ表記は平面図にもあるため、それだけでは展開図にしません）。DXFは平面図として読み、展開図らしい表記があれば「PDFで書き出して」と案内します。画像・JSONは平面図として扱います。
- 図面一覧で図面名を押すと、その図面（平面図か展開図）だけを表示します（もう一度押すか「両方表示に戻す」で両方）。
- 判別の結果と理由は図面一覧の下に表示します。違っていれば、図面名の横の「↑↓」で入れ替えられます（PDFのみ）。展開図として扱っても壁を自動で読み取れない場合は、「PDFの縮尺」で表示し、四角で壁紙の範囲を指定します。
- 図面名をクリックすると切り替わり、「×」で外せます。図面ごとに、手で指定した部屋・範囲、選んだ部屋・壁、縮尺を覚えています。
- 平面図の部屋はカーペットのサイズとお部屋パースの奥行に、展開図の壁は壁紙のサイズ（お部屋パースの幅・壁の高さ）に反映します。展開図で壁を選んでいる間は、部屋を選び直しても壁紙のサイズは変わりません。
- 図面はページを開いている間だけ保持します（ページを再読み込みすると消えます）。

## カーペット用デザイン画像の変換（4画像の比較）

「① カーペット用デザイン画像」を選ぶと、元画像と3通りの自動変換を並べて表示します。

| 変換 | 内容 |
|---|---|
| ① 標準色のみ | 無償の標準色（基本16色＋OP-03・05）から選んだ16色 |
| ② 標準色＋オプション3色 | 標準色13色＋有償オプション3色＝計16色 |
| ③ 最大表現 | 標準色とオプションカラーの全色から、元画像に最も近い16色 |

「この変換で進める」を押した変換が、見積もり・パース・PSD保存・注文の対象になります（最初は①）。色は下のパレットで手動でも変えられます。

## 展開図から壁紙のサイズを割り出す

壁の展開図（立面図）のPDFを CAD の欄に入れると、平面図の代わりに「壁」を読み取ります。

1. **壁の検出**: 各段の端にある天井高の表記（例: `2,700` と `▼FL±0`）から壁の高さ、図の上にある寸法から壁の幅を読み取り、壁ごとに番号を付けて図面上に枠を表示します。縮尺は寸法の並びから自動で判定します（「PDFの縮尺」に数字を入れると、その縮尺を使います）。
2. **クロス貼りの壁**: 図面の仕上げ表記に「クロス」「壁紙」とある壁は、紫色の枠と「クロス」の印で表示します。「クロス貼りの壁だけ表示」で絞り込めます。
3. **壁紙のサイズに反映**: 壁を選ぶと、その幅・高さを、お部屋パースの「幅」「壁の高さ」（壁紙PSD・注文の寸法）に設定します。
4. **壁紙の合計**: 一覧の左のチェックで、部屋の壁を「壁紙の合計」に入れます（「この図面の壁を合計に：全部／クロス貼りだけ／解除」でまとめて選べます。複数の展開図にまたがって合計できます）。面数・幅の合計・面積の合計と、910mm幅ロールの巾数・長さの合計（左右10mmずつ重ねるため壁ごとに 幅÷890 を切り上げ、1巾 = 壁の高さ + 上下100mmずつ）を表示し、注文メールにも記載します。扉・窓などの開口は差し引きません。
5. **範囲を指定**: 腰壁の上だけなど、壁紙を貼る範囲が壁の一部のときは、「四角で壁紙の範囲を指定」で図面の上を囲むと、その実寸を使います。

注意: 文字が埋め込まれていないPDF（文字がアウトライン化されたもの・スキャン）では読み取れません。その場合は四角で範囲を指定してください。寸法の配置が一般的でない図面では、壁の分け方がずれることがあります。

## 壁紙の減色（任意）

壁紙はCMYKで印刷するため、既定では減色しません。元画像の色のまま、お部屋パース・3D・PSD・印刷用データ・注文に使います（保存・印刷は元画像のフル解像度から作ります）。減色したい場合は、「② 壁紙用デザイン」の「壁紙を減色する」にチェックを入れると、階調表現（誤差拡散）とカラーパレットの欄が表示され、従来どおり減色します。

## 壁紙の貼り方

「② 壁紙用デザイン」の「貼り方」で選びます。どの貼り方でも、画像の縦横比は変えません。お部屋パース、CADお部屋シミュレーションの3D、壁紙PSD、注文用の壁紙変換後画像に反映します。

| 貼り方 | 内容 |
|---|---|
| 柄を繰り返して貼る（既定） | 「柄の大きさ（1リピートの横幅、mm。既定 910）」の大きさで、天井から柄を繰り返します。壁の角で柄が途切れず、隣の壁へ続きます |
| 1枚を壁ごとに中央に貼る | 1枚の画像を、どの壁でも同じ大きさで、壁ごとに中央に合わせます。100%＝部屋の一番長い壁と壁の高さを覆う大きさ |
| 1枚を部屋を一周して続けて貼る | 1枚の画像を、部屋の壁に沿って帯のように貼ります。壁の角で途切れず隣の壁へ続きます。100%＝部屋の壁の合計の長さを覆う大きさ。壁紙PSD・注文の画像は、奥の壁（お部屋パースの幅）にあたる部分です |

画像の大きさは、CAD表示の「壁紙の巾の枠」の「画像の大きさ」スライダー（20〜300%）で変えられます（小さくしたときの余白は白、はみ出した部分は切り取り）。100%は、壁に加えて印刷の裁断代（上下100mm）と巾の重なり（左右10mm）まで画像が入る大きさです。

展開図で壁を指定するボタンは、平面図で部屋を指定するときと同じです（移動／四角／多角形／壁を移動／形を変える／全体／＋ 拡大／− 縮小／角を直角にそろえる／自動で出た壁を隠す）。

## 壁紙の巾の枠（切り分けなし・3レイヤー保存）
展開図で壁を選ぶと、展開図の下に「壁紙の巾の枠」が表示されます（お見積もりページで使えます）。

- **巾（横幅）**：850〜930mm（1mm刻み、初期 910mm）。**合わせ代**（隣り合う巾が重なる幅）：6〜15mm（0.5mm刻み、初期 10mm）。
- 画像は巾ごとに切らず1枚のまま表示します（壁の左右には、合わせ代と同じ幅＝初期10mmの余白を取ります）。高さは「壁の実寸 ＋ 上下100mmずつ」、幅は「巾の数 × 1巾が受け持つ幅 ＋ 合わせ代」です。
- 「CAD図面を表示」「画像（元画像）を表示」「枠を表示」で、それぞれ表示／非表示にできます。枠は巾ごとに赤とオレンジで交互に描き、重なる部分が分かるようにします。紫の実線は壁の範囲（多角形で囲んだ変形の壁は、その形どおり。カット線も壁の中だけ）で、隣り合う巾が重なる部分の真ん中（赤の枠の端とオレンジの枠の端の間）に、紫のカット線を壁の範囲の上下の線とつなげて表示します。「枠を右寄せスタート」にチェックを入れると、右の端から巾を並べます（外すと左の端から）。この寄せ方はこの図とPSD保存に反映されます（分割ZIPは左から）。
- **壁をつなげる（部屋一周）**：チェックを入れて壁の番号を時計回りの順に入れる（例: 1,2,3,4）と、その壁を横に並べ、柄が途切れずに一周つながるように貼ります。「＋ 選んでいる壁を追加」で一覧で選んだ壁を追加、「全部（番号順）」ですべての壁を入れます。「左回り（反時計回り）でつなげる」にチェックを入れると、最初の壁から逆の順につなげます（外すと右回り）。高さが違う壁は「下（床）合わせ」か「上（天井）合わせ」を選べます。巾の数・枠・PSD保存も、つなげた全体で作ります。3D表示でも、巾の枠に出している壁（1面でも、つなげた壁でも）を、平面図で選んだ部屋の中で長さが最も合う壁に、同じ画像・同じ位置・実寸で貼ります（ほかの壁はこれまでどおり）。平面図で部屋を選んでいるときは、つなげた壁の幅の合計と部屋の周長、壁ごとの長さと部屋の辺を比べ、合わなければ赤い警告で差を表示します。
- 「表示を動かす」「画像を移動」「枠を移動」で、ドラッグや「← 左／右 →／↑ 上／↓ 下」ボタン（矢印キーも可。画像・枠は10mm、Shiftで100mm）の動かす対象を選びます。「位置を戻す」で画像と枠の位置が元に戻ります。動かした量はPSD保存にも反映されます。
- 「画像の大きさ」（20〜300%）で壁紙の画像を壁の中心から拡大縮小できます（保存・3D・パースにも反映）。「画像の濃さ」は画面の表示だけで、保存する画像は濃さ100%です。
- 図は「＋ 拡大」「− 縮小」「全体」ボタンやマウスホイールで拡大縮小でき、ドラッグ・「← 左／右 →／↑ 上／↓ 下」ボタン・矢印キー（Shiftで大きく）で動かせます。
- 「壁紙データを保存（PSD・3レイヤー）」で、CMYK・1px=1mm・25.4dpiのPSDを保存します（作成中は進み具合を表示。幅が30000mmを超えるときは、Photoshopの大きなドキュメント形式＝PSBで保存）。レイヤーは ①CAD図面 ②壁紙の画像（切り分けなし） ③巾の枠 の3つです。
- ここで決めた巾・合わせ代は、「壁紙へ印刷用に保存」（910mm幅に分割するZIP）や、壁紙の合計（巾数）、お部屋パースの余白にも反映されます。

## 壁紙へ印刷するデータ（910mm幅）

「🖨 壁紙へ印刷用に保存（910mm幅に分割・ZIP）」で、壁のデザインを910mm幅（ロール幅）の巾に分け、ZIPで保存します。

- 1巾 = 幅 910mm × 高さ（図面の壁の高さ + 上下100mmずつの裁断代）。CMYK・8bit・PSD・25.4dpi（1px = 1mm）。
- 隣の巾とは合わせ代（初期10mm）だけ重なります（1巾が受け持つ壁の幅は 900mm。重なりの真ん中がカット線）。重なり部分には隣の巾と同じ柄が入ります。
- 各巾が受け持つ壁の範囲を、赤枠（別レイヤー「②赤枠」）で示します。印刷しないときはレイヤーを非表示にしてください。
- ZIPの中身:
  - `01_元データ_…`：アップロードされた壁紙用デザイン画像（そのまま）
  - `02_変換後全体データ_…psd`：減色後のデザインを壁全体に貼った絵（全巾分。左右の重なり・上下の裁断代を含む。赤枠＝壁の範囲、縦線＝巾の境目）
  - `03_910mm幅ロール連続データ_…psd`：910mm幅の巾を縦に1本につなげたデータ。1巾目は天井側が上、2巾目は180°回転して天井側が下…と交互になります（1巾目の上をA・下をCとすると AC→CA→AC→CA）。隣り合う巾は天井側どうし・床側どうしでつながります。高さが30,000mm（PSDの上限）を超えるときは、複数ファイルに分けます
  - `04_巾ごと/`：1巾ずつのPSD（すべて天井側が上）
  - `README_印刷データについて.txt`：寸法の説明
- 「壁紙デザイン画像を保存」（1面分のPSD）も、高さは同じく「壁の高さ + 上下100mmずつ」です。ガイドは、壁の範囲の赤枠と、巾の境目（890mmごと）の縦線です。

## 壁紙のPSD（CMYK）

壁紙の画像は CMYK（8bit・25.4dpi・実寸1px=1mm）のPSDで保存します。RGBからCMYKへの変換にICCプロファイルは使わない単純変換のため、印刷色は校正してください。床（カーペット）のPSDは従来どおりRGBです。

## 他のページから使う（CAD表示）

各ウィジェットは `element.cfpWidget` から操作できます。

```js
const w = document.querySelector('.cad-floor-plan-widget').cfpWidget;
w.renderer.setFloorTexture(canvas.toDataURL());   // 床の画像
w.renderer.setWallTexture(imageUrl);              // すべての壁
w.renderer.getAreas();                            // { floorArea, wallArea }（㎡）
```

PDF.js の読み込み先は、フィルター `cad_floor_plan_pdfjs_url` と `cad_floor_plan_pdfjs_worker_url` で変更できます。Three.js と PDF.js は cdnjs から読み込みます。

## バージョンについて

プラグインのバージョンは次の3か所に書かれています。変更するときは、まとめて更新してください。

- `cad-floor-plan.php` のヘッダー `Version:`
- 同ファイルの `CFP_VERSION`
- `package.json` の `version`

変更後は `./build-embed.sh` で埋め込み版を作り直し、zip も作り直します。

あわせて `CHANGELOG.md` に変更内容を追記します。バージョンを上げると、次回のアクセス時に保存済みバージョンが更新されます（`maybe_upgrade()`）。
