# Changelog

## 2.28.0
- 壁紙の減色を任意にした（既定は減色しない）。壁紙はCMYK印刷のため、元画像の色のまま、お部屋パース・CADの3D・壁紙PSD・印刷用データ・注文に使う。保存・印刷は元画像のフル解像度から作る。
- 「② 壁紙用デザイン」に「壁紙を減色する」チェックを追加。チェックすると、従来どおり階調表現・カラーパレットで減色する（チェックしない間は、これらの欄を隠す）。
- 注文メールの壁紙の行は、減色しないとき「減色なし（元画像の色のまま・CMYK印刷）」と記載し、変換後画像のファイル名は wall_converted_… になる。

## 2.27.0
- 壁紙の印刷用ZIPに、次のデータを追加。
  - 01_元データ：アップロードされた壁紙用デザイン画像（そのまま）。
  - 02_変換後全体データ：減色後のデザインを壁全体に貼った絵（全巾分、左右の重なり・上下の裁断代を含む、赤枠と巾の境目のレイヤー付き）。
  - 03_910mm幅ロール連続データ：910mm幅の巾を縦に1本につなげ、1巾おきに180°回転したデータ（1巾目の上をA・下をCとすると AC→CA→AC→CA）。隣り合う巾が天井側どうし・床側どうしでつながる。高さ30,000mmを超えるときは複数ファイルに分ける。
  - 従来の巾ごとのPSDは「04_巾ごと」フォルダに移動。

## 2.26.0
- 「🖨 壁紙へ印刷用に保存（910mm幅に分割・ZIP）」を追加。壁のデザインを910mm幅（ロール幅）の巾に分割し、巾ごとのCMYK PSD（1px=1mm・25.4dpi）とREADMEをZIPにまとめて保存する。
  - 1巾の高さ = 図面の壁の高さ + 上下100mmずつの裁断代。
  - 横は隣の巾と左右10mmずつ重なる（1巾が受け持つ壁は890mm）。重なり部分は隣の巾と同じ柄。
  - 各巾が受け持つ壁の範囲を赤枠（別レイヤー）で示す。
- 「壁紙デザイン画像を保存（CMYK PSD）」も、高さを「壁の高さ + 上下100mmずつ」に変更（以前は下に200mm）。ガイドは、壁の範囲の赤枠と、巾の境目（890mmごと）の縦線。
- 1枚の貼り方で、保存した画像の上端に白い帯が出ることがあった不具合を修正（壁の部分の中央に合わせるようにした）。
- 壁紙の合計の巾数を、910mm幅を左右10mmずつ重ねる前提（890mmごと）、1巾の長さを「壁の高さ + 上下100mmずつ」で計算するように変更。

## 2.25.0
- 壁紙の「貼り方」を選べるようにした（「壁に柄を繰り返して貼る」のチェックを置き換え）。
  - 柄を繰り返して貼る：壁の角で柄が途切れず、隣の壁へ続くようにした（CADの3Dは部屋を一周して連続、お部屋パースは角を柄の区切りにして左右へ続く）。
  - 1枚を壁ごとに中央に貼る：従来の1枚表示（どの壁でも同じ大きさ、大きさスライダー付き）。
  - 1枚を部屋を一周して続けて貼る（新規）：1枚の画像を部屋の壁に沿って帯状に貼り、角で途切れず隣の壁へ続く。100%で部屋の壁の合計の長さを覆う大きさ。壁紙PSD・注文の画像は奥の壁（幅）にあたる部分。
- お部屋パースの横の壁で、画像が左右反転して見えていた不具合を修正。

## 2.24.0
- 壁いっぱいの1枚表示に「1枚表示の画像の大きさ」スライダー（10〜300%、既定100%）を追加。100%は部屋の一番長い壁と壁の高さを覆う大きさ。中央合わせのまま拡大・縮小でき、縦横比は変えない。小さくしたときの余白は白（お部屋パース・CADの3D・壁紙PSD・注文用の壁紙変換後画像）。
- 繰り返し表示のときは「柄の大きさ（mm）」、1枚表示のときはスライダーだけを操作できるようにした。

## 2.23.0
- 壁いっぱいの1枚表示で、壁をまたいでも画像が同じ大きさになるようにした（以前は壁ごとに拡大率が違い、短い壁ほど大きく写っていた）。画像の大きさは、部屋の一番長い壁と壁の高さの両方を覆える大きさに統一し、壁ごとに中央に合わせる（お部屋パースの奥・横の壁、CADの3Dの全部の壁、壁紙PSD、注文用の壁紙変換後画像）。

## 2.22.0
- 壁いっぱいの1枚表示（「壁に柄を繰り返して貼る」をオフ）でも、画像の縦横比を変えないようにした。壁を覆う大きさに拡大・縮小し、中央に合わせて、はみ出した部分は切り取る（お部屋パース・CADの3D・壁紙PSD・注文用の壁紙変換後画像）。

## 2.21.0
- 壁紙の画像を、縦横比を変えずに繰り返して表示するようにした（お部屋パース・CADお部屋シミュレーションの3D・壁紙PSD・注文用の壁紙変換後画像）。「② 壁紙用デザイン」に「柄の大きさ（1リピートの横幅 mm、既定 910）」を追加。縦は画像の縦横比から決まる。柄は天井（上端）・左端から貼り始める。
- 「壁に柄を繰り返して貼る」を外すと、従来どおり壁いっぱいに1枚で伸ばす。

## 2.20.0
- 図面が平面図（床）か展開図（壁）かを、図面の中身から判別するようにした。PDFは、壁の高さの表記（▼FL と天井高）と寸法から壁を読み取れたら展開図。読み取れなくても「展開図」「立面図」「姿図」「ELEVATION」の表記が「平面図」「間取」などより多ければ展開図。それ以外は平面図（▼FL などの高さ表記は平面図にもあるため、それだけでは展開図にしない）。DXFは文字を調べ、展開図らしいときは「PDFで書き出して」と案内。画像・JSONは平面図として扱う。
- 判別の結果と理由を図面一覧の下に表示。違っていれば図面名の横の「⇄」で入れ替えられる（PDFのみ）。
- 展開図として扱ったが壁を自動で読み取れないときは、「PDFの縮尺」の縮尺で図面を表示し、四角で壁紙の範囲を指定できる。

## 2.19.0
- 展開図の壁を、チェックで「壁紙の合計」に入れられるようにした。複数の展開図にまたがって合計できる。合計は、面数・幅の合計・面積の合計・910mm幅ロールの巾数と長さの合計（1巾 = 壁の高さ + 裁断代200mm）。扉・窓などの開口は差し引かない。
- 「この図面の壁を合計に：全部／クロス貼りだけ／解除」のボタンを追加。
- 注文メールに「壁紙の合計（展開図から）」を記載。

## 2.18.0
- 図面を複数まとめて読み込めるようにした（ファイル選択で複数選ぶ、または複数ドロップ）。読み込んだ図面は「平面図（床 → カーペット）」「展開図（壁 → 壁紙）」に分けて一覧表示し、クリックで切り替え、「×」で外せる。PDFは展開図かどうかを自動で判定する。
- 平面図と展開図を同時に使えるようにした。平面図で選んだ部屋はカーペットのサイズとお部屋パースの奥行に、展開図で選んだ壁は壁紙のサイズ（お部屋パースの幅・壁の高さ）に反映する。展開図で壁を選んでいる間は、部屋を選び直しても壁紙のサイズは変えない。
- 図面を切り替えても、図面ごとに、手で指定した部屋・壁紙の範囲、選んだ部屋・壁、縮尺を覚えておく。

## 2.17.0
- 展開図（壁の立面図）のPDFを読み込むと、壁を自動で割り出すようにした。各段の天井高の表記（例: 2,700 と ▼FL±0）から壁の高さを、図の上の寸法から壁の幅を読み取り、壁ごとに一覧と図面上の枠で表示する。縮尺は寸法の並びから自動判定（1:50 など）。
- 図面の仕上げ表記で「クロス」「壁紙」と書かれた壁は「クロス」と表示し、「クロス貼りの壁だけ表示」で絞り込める。
- 壁を選ぶと、幅・高さを壁紙のサイズ（お部屋パースの幅・壁の高さ、壁紙PSD・注文の寸法）に反映する。
- 腰壁の上だけなど、壁紙を貼る範囲を図面の上で四角に囲んで指定することもできる（縮尺から実寸を計算）。

## 2.14.0

## 2.9.0
- 自動で部屋を読み取れない図面（壁・寸法線・家具が重なった CAD の PDF など）のために、図面の上で部屋を指定する機能を追加。「四角」（対角の2点をドラッグ）と「多角形」（角を順にクリック、直角にそろえる）、ホイールでの拡大縮小、移動に対応。指定した部屋は一覧に追加され、個別に削除できる。大きさは、PDFの縮尺（1:N）または「この大きさにする」で決まる。
- PDF・画像で自動検出が20個を超えるとき（家具や設備の囲みが多い図面）は、自動検出を隠し、部屋の指定画面を開く。「自動で出た部屋を隠す」で切り替え可能。
- PDFで閉じた部屋が見つからないときは、エラーにせず、PDFのページを画像として表示し、読み取りまたは手動指定に進む。
- PDFのページを高解像度で扱うため、「すき間を閉じる」を画像の大きさに合わせて補正。

## 2.8.0
- スキャンしたPDF（中身が画像のPDF）を、画像の図面として自動で読み取るようにした。縮尺の入力や、すき間・線の濃さの調整は、PNG / JPEG と同じ。
- PDFで部屋を検出できないときのエラー文を、原因が分かる内容に変更。縮尺が合っていない場合は、読み取れた最大の図形の大きさと、入れるべき縮尺の目安を表示する。線が閉じていない場合は、その旨を表示する。

## 2.7.0
- CADの入稿に PNG / JPEG（WebP）の図面画像を追加。線で囲まれた部分を部屋として読み取り、元の画像に重ねた平面図で確認・選択できる。ドアの開口などのすき間は「すき間を閉じる」、線の濃さは「線を検出する濃さ」で調整できる。部屋の中の家具などの囲みは除外し、ほぼ長方形の部屋は長方形に整える（L字などは形を保つ）。
- 画像には縮尺が無いため、選んだ部屋の横幅または奥行の実際の長さを入力して大きさを合わせる。入力するまでは「仮」と表示し、見積もり・壁紙サイズには反映しない。

## 2.6.0

- 壁紙PSDと注文の寸法に使う「壁の幅」「壁の高さ」の入力欄、床・壁紙デザイン画像の保存ボタンは、「壁紙のサイズ・デザイン画像の保存」欄として残した。図面から読み取った部屋のサイズは、この欄とカーペットサイズに反映される。

## 2.5.0
- 図面から読み取ったサイズを、見積もりとお部屋パースに自動反映。部屋の外形（幅×奥行）から、カーペットの横幅・縦幅（500mm単位に切り上げ。10mm以下の端数は切り捨て）、パースの幅・奥行・壁の高さを設定する。四角でない部屋は、外接する四角で見積もられる旨と実際の床面積を表示。「図面のサイズを見積もり・パースに反映する」で切り替え可能。
- 図面に部屋が複数あるとき、平面図のクリックまたは一覧から、3Dに表示する部屋を選べるようにした（最初は最大の部屋）。部屋の並びは図面上の位置の順（上から下、左から右）。
- 図面内の文字（DXF の TEXT / MTEXT、PDF の文字）から、部屋の名前を自動で付ける。数字だけの文字（寸法など）は除外。DXF の Shift_JIS など、書き出し時の文字コードに対応。
- DXF の単位を自動判定（図面の設定 → 図面の大きさから判定）。画面で mm / cm / m を手動指定することも可能。
- 縮尺・単位を変更して再読み込みしても、選んだ部屋を保持。
