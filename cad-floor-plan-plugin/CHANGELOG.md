# Changelog

## 2.4.0
- CADお部屋シミュレーションの3Dパースに、①カーペット用・②壁紙用の変換後（減色後）のデザイン画像を自動で反映。デザインを再処理するたびに更新される。床・壁の片方だけでも反映される。
- 壁のテクスチャを後から差し替えても反映されない不具合を修正。
- 照明を調整し、床・壁の色が白飛びしにくいようにした。

## 2.3.0
- 制電マーク・防炎マークを、メディアライブラリにアップロード済みの画像から自動で探して表示（画像のタイトルに「制電マーク」「防炎マーク」を含むもの。例: `seiden_mark_制電マーク.jpg`、`bouen_mark_防炎マーク.jpg`）。`assets/badges/` に画像を置いた場合は、そちらを優先。フィルター `cfp_badge_url` で差し替え可能。

## 2.2.0
- 制電マーク・防炎マークが表示されない問題に対応。画像は `assets/badges/` の `seiden.*` と `bouen.*`（png / jpg / jpeg / webp / gif / svg）を置くだけで表示される。画像がない間は、壊れた画像アイコンを出さずにマークを隠す。

## 2.1.0
- 自動作成ページに Cocoon のページ設定を適用: ページタイプ「本文のみ（フルワイド）」、タイトル・読む時間・目次を表示しない。Cocoon 以外のテーマでは無視される。
- 2.0.0 で作成済みのページにも、更新時に同じ設定を適用。

## 2.0.0
- 「壁紙・カーペットシミュレーション」固定ページを有効化で自動作成（無効化で削除）。元のツール（`wallpaper-carpet-tool.html`）にCAD表示を組み込んだ内容を、ショートコード `[wallpaper_carpet_simulator]` で表示。
- Design Order Mailer（注文メール送信・デザインファイル保存）を同梱。元の同名プラグインが有効なときは同梱版を停止し、二重動作を防ぐ。テーブル・設定・AJAXアクション名は元のまま。
- 同じURLの既存ページがあるときは別URLで作成し、管理画面で案内。
- 1.x で作成されたCAD単体ページを、2.0.0 への更新時に合体版へ自動変換。
- 注文メール用スクリプトは、シミュレーションを置いたページだけで読み込む。

## 1.3.1
- 有効化時に、ショートコード入りの既存ページを流用する処理が動かない不具合を修正。

## 1.3.0
- プラグインを無効化すると、プラグインが作成した固定ページを削除（既存ページを流用した場合は削除しない）。

## 1.2.0
- プラグインなしで使える埋め込み版 `dist/cad-floor-plan-embed.html` を追加（カスタムHTMLブロックに貼るだけ）。`build-embed.sh` で生成。

## 1.1.0
- 有効化時に固定ページ「CADお部屋シミュレーション」を自動作成。管理画面から再作成も可能。
- PDFが読み込めない不具合を修正（PDF.jsを自動で読み込み、描画命令を正しく解析。縮尺指定に対応）。
- DXF解析を作り直し（LWPOLYLINE / POLYLINE / LINE、`$INSUNITS` による単位換算、線のつながりから閉じた輪郭を検出）。
- 部屋の輪郭を検出できない場合は、ダミーの部屋を出さずエラーを表示。
- 3D表示を修正（凹形状のL字などを正しく描画、室内側から見える壁、カメラの自動フィット、床・壁へのテクスチャ貼り付け）。
- 床・壁紙の画像を直接アップロードして貼れるようにした。
- 1ページに複数ウィジェットを置けるように変更。ショートコードのあるページだけでスクリプトを読み込む。
- 実体のなかったREST `/parse` エンドポイントと、存在しない管理画面用ファイルの読み込みを削除。
- 版数管理（`maybe_upgrade()`）と `uninstall.php` を追加。

## 1.0.0
- 初版（DXF / PDF / JSON 読み込み、3D表示、ショートコード）。
