# Changelog

## 2.51.0
- 「① カーペット用デザイン画像」の変換を、元画像と3通りの自動変換の計4画像で比べて選べるようにした。
  - 元画像（オリジナル）
  - ① 標準色のみ：無償の標準色（基本16色＋OP-03・05）から、元画像に最も近い16色
  - ② 標準色＋オプション3色：標準色13色＋有償オプション3色＝計16色
  - ③ 最大表現：標準色とオプションカラーの全色（46色）から、元画像に最も近い16色
  - 色の選択は、元画像の色の分布から、色の近さ（Lab）の合計が最も小さくなる組合せを自動で探す（貪欲法＋入れ替え）。各変換に、使用色のチップ・色数・有償オプションの色数を表示。
  - 「この変換で進める」で、その色の組合せが、お見積もり（オプションカラー追加料金）・パース・PSD保存・ご注文の対象になる。新しい画像を選んだときは、①を選んだ状態から始まる。
  - 色の手動選択（下のパレット）も従来どおり使え、手動で変えたときは、その結果を別に表示する。
