# Changelog

## 1.1.0
- 有効化時に固定ページ「CADお部屋シミュレーション」を自動作成。管理画面から再作成も可能。
- PDFが読み込めない不具合を修正（PDF.jsを自動で読み込み、描画命令を正しく解析。縮尺指定に対応）。
- DXF解析を作り直し（LWPOLYLINE / POLYLINE / LINE、`$INSUNITS` による単位換算、線のつながりから閉じた輪郭を検出）。
- 部屋の輪郭を検出できない場合は、ダミーの部屋を出さずエラーを表示。
- 3D表示を修正（凹形状のL字などを正しく描画、室内側から見える壁、カメラの自動フィット、床・壁へのテクスチャ貼り付け）。
- 床・壁紙の画像を直接アップロードして貼れるようにした。
- 1ページに複数ウィジェットを置けるように変更。ショートコードのあるページだけでスクリプトを読み込む。
- 実体のなかったREST `/parse` エンドポイントと、存在しない管理画面用ファイルの読み込みを削除。
- 版数管理（`maybe_upgrade()`）と `uninstall.php` を追加。

## 1.0.0
- 初版（DXF / PDF / JSON 読み込み、3D表示、ショートコード）。
