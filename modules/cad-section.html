🏗️ CADデータからお部屋をシミュレーション（DXF / PDF / JSON対応）

AutoCADやIllustratorで作成した間取り図（DXF形式）、またはベクターPDF、JSON形式の寸法データを読み込んで、 リアルタイムに複雑な間取りのお部屋パースを表示できます。
床のカーペット・複数の壁紙を別々にシミュレーション可能です。

対応形式：
• DXF（AutoCAD）
• PDF（ベクターPDF）
• JSON（カスタム形式）
ドラッグ&ドロップも対応
ファイル名 未選択
ファイルサイズ -
床面積 -
壁面積 -
検出された部屋 0
📝 JSON形式のサンプル：
{
  "rooms": [{
    "id": "room_1",
    "vertices": [[0,0], [5000,0], [5000,3000], [0,3000]],
    "walls": [{
      "from": 0, "to": 1, "length": 5000, "height": 2800, "material": "wallpaper"
    }],
    "floor": {"material": "carpet"}
  }],
  "metadata": {"source": "json", "scale": 1}
}
